Method and limits

Both models receive the same text, instructions and mailbox choices. Expected labels remain local. OpenAI uses openai/gpt-6-luna-decisions on its OpenAI route; Jev uses typesafe-ai/jev on its TypeSafe route. Both pass through Vercel AI Gateway. Dispatch order alternates and provider routes are pinned.

The run offered one letter per second with capacity for three paired requests. Median and p95 include valid completed responses, including late ones. The separate hard timeout is 20 seconds. First-draw timings do not include envelope landing or measure display compositor presentation.

The dataset is synthetic and small. Network, gateway, model tokenization and provider placement differ. These measurements are exploratory; this test does not establish a universal speed winner. Shared paired admission measures useful timely routing under that admission policy, not each provider’s independent maximum throughput.
